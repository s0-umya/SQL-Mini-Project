<h1 align="center">🛒 SQL Mini Project — Retail Store Analysis</h1>

<p align="center">
  A comprehensive SQL-based analytical project that explores retail store data to uncover meaningful business insights through structured queries, aggregations, and data-driven exploration.
</p>

---

## 📖 Overview

This project demonstrates the practical application of **SQL** and **MySQL** in analyzing a retail store's transactional and operational data. It covers a range of query techniques — from basic `SELECT` statements to complex joins, subqueries, and aggregate functions — to extract actionable insights about sales performance, product trends, and customer behavior.

The full analysis, including queries and results, is documented in a detailed PDF report.

---

## ✨ Features / Highlights

- 🔍 **Data Exploration** — Thorough exploration of retail store tables and schema
- 📊 **Sales Analysis** — Revenue breakdowns, top-selling products, and sales trends
- 🧮 **Aggregate Functions** — Use of `SUM`, `COUNT`, `AVG`, `MAX`, `MIN` for statistical insights
- 🔗 **Joins & Subqueries** — Multi-table queries combining customer, product, and order data
- 📈 **Business Insights** — Data-driven conclusions on retail performance metrics
- 📄 **Comprehensive Documentation** — All queries and results documented in a structured PDF

## 🚀 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/s0-umya/SQL-Mini-Project.git
   cd SQL-Mini-Project
   ```

2. **View the project report**
   - Open `docs/SOUMYADAS_SQL_MINI_PROJECT_RETAIL_STORE.pdf` to review the complete analysis

3. **Reproduce the analysis**
   - Set up a MySQL database instance
   - Create the retail store schema and import the sample data as described in the report
   - Execute the SQL queries from the PDF to replicate the results
